# BOMOS self-assessment

Beheert u een standaard of stelsel? Of gaat u er een ontwikkelen? Voer zelfstandig een BOMOS-assessment uit.

Dit is een interactieve manier om je eigen organisatie een spiegel voor te houden op welke vlakken je het beheer al op orde is of verder kan verbeteren.

## Gebruikssituaties
U kunt een BOMOS self-assessment solo invullen, maar het leent zich ook uitstekend voor een teamsessie.  

Doe je het assessment alleen?  Dat werkt als volgt: gebruikt een LLM model naar keuze en gebruik de data en instructies die in deze ruimte staan. Hiermee creeer je een digitale adviseur waarmee je samen het assessment doorloopt en die je van advies voorziet. Deze werkwijze vervangt de regelhulp voor BOMOS.

Daarnaast is er de klassieke assessment te gebruiken door het invullen een spreadsheet. Deze manier is geschikt om als groep en onder begeleiding van een BOMOS-deskundige een assessment uit te voeren. De input en het gesprek daarover vormt dan de basis om samen met stakeholders terug te blikken en de prioriteiten voor de komende periode te bepalen. Logius kan hierbij ondersteunen.

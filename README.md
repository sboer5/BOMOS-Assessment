# BOMOS self-assessment

Beheer je een standaard of stelsel? Of gaat u er een ontwikkelen? Voer zelfstandig een BOMOS-assessment uit.

Dit is een interactieve manier om je eigen organisatie een spiegel voor te houden op welke vlakken je het beheer al op orde is of verder kan verbeteren.

## Gebruikssituaties
Een BOMOS self-assessment kan je alleen invullen, maar een assessment leent zich ook uitstekend voor een teamsessie.  

Doe je het assessment alleen?  Dat werkt als volgt: gebruikt een LLM model naar keuze en gebruik de data en instructies die in deze ruimte staan. Hiermee creeer je een digitale adviseur waarmee je samen het assessment doorloopt en die je van advies voorziet. Deze werkwijze vervangt de regelhulp voor BOMOS.

Daarnaast is er de klassieke assessment te gebruiken door het invullen een spreadsheet. Deze manier is geschikt om als groep en onder begeleiding van een BOMOS-deskundige een assessment uit te voeren. De input en het gesprek daarover vormt dan de basis om samen met stakeholders terug te blikken en de prioriteiten voor de komende periode te bepalen. Logius kan hierbij ondersteunen.

## Instructie alleen aan de slag

Gebruik een LLM naar keuze die RAG ondersteunt (dat betekent dat je bestanden kan toevoegen aan een ruimte die de LLM dan gebruikt bij chats). 

Voeg een url toe naar de documentatie in de map ../dataset-assessement of voer een upload uit de documenten in de map dataset-assessment toe. Hiermee geef je de LLM de context voor het assessment.

Als dat is gelukt: kopieer en plak de prompt uit het bestand prompt-assessment.md en start het assessment.

Let op dat je rekening houdt met informatieveiligheid en privacy met het gebruik van een LLM. Gebruik daarom geen geheime of persoonlijke gegevens in je antwoorden. Hou er vervolgens rekening mee dat een LLM fouten maakt.
